# Name policy

The code in this repository is licensed under the MIT License (see [LICENSE](LICENSE)). The license covers the code, not the name. This page says how the name **Ennyn** may be used.

## You may

- Say that your project uses, extends or is compatible with Ennyn.
- Use the name in articles, talks, tutorials and package descriptions that refer to this project.
- Redistribute unmodified releases under the name Ennyn.

## Please ask first, or use another name

- A fork or modified distribution. Rename it; you may say it is "based on Ennyn".
- A product, service, company or domain name that contains "Ennyn".
- Anything that suggests the maintainers endorse or certify your work.

## Origin of the name

*Ennyn* is Sindarin for "gates", from J.R.R. Tolkien's writings. This project is not affiliated with, sponsored or endorsed by the Tolkien Estate, Middle-earth Enterprises or any of their licensees. No claim is made to any Tolkien-related trademark.

Questions about the name: open an issue in this repository.
